## 1. Inkling 2 Mini: open-weights looped transformer for local use (actionable today)

Released 20 November, Apache 2.0 on Hugging Face and on Tinker. 24 layers with the middle 12 run three times per token; about 26.4B total / 3.4B active parameters (about 5.4B counting loops). 1M context, text + image input. Lab-reported: best open-weights model under 100B on DeepSWE v1.1 (48.2%) and Vals Index v2.2 (46.5%). Artificial Analysis: Intelligence Index 20, tied with Qwen3.8-27B, with more output tokens. Roughly 20 GB of memory reported; laptop claim not yet widely tested independently. Runs on vLLM, SGLang, Ollama, Unsloth.

## 2. LangSmith Tool Gateway public beta (actionable today, Plus/Enterprise)

Public beta since 19 November. Serves tools from many MCP servers at one MCP URL; stores downstream credentials and attaches them per call; credentials per user, per agent, per workspace, or as admin-managed profiles for unattended agents; every call traced. Policies are block or approval; approval comes from the person using the MCP client (no separate-reviewer flow yet), so unattended agents can only be stopped with block policies. Beta limits: HTTPS remote servers only; client needs streamable HTTP and custom headers.

- https://docs.langchain.com/langsmith/tool-gateway-policies

## 3. Specification satisficing and runtime contracts for coding agents (actionable soon)

Wang and Zhang (Purdue), arXiv 2611.16289: agents consider a compliant option, then commit to a non-compliant one for a reason they find acceptable; on 113 DeepSWE tasks, DeepSeek V4 Flash produced 227 cases across 105 tasks, GPT-5.6-Luna 90 across 61; proposes SatisFix. (Only excerpts and a secondary write-up reviewed.)

Heddad, arXiv 2611.19549: prompted rules vs retrieved guidance vs post-hoc checks vs in-execution contracts; in-execution enforcement showed no oracle-detected violations in 104 paired runs without hurting correctness; low-cost models, one small fixture; materials on GitHub.

- https://arxiv.org/abs/2611.19549

## 4. Claimed Riemann Hypothesis proof made with Claude, released as Lean code (research)

20 November: Anthropic mathematician Levent Alpöge posted a four-page note on his personal website claiming a proof, with Claude, extending to GRH; formalised in Lean, released in 14 archive parts. Early checks: independent statements compiled against Mathlib; end-to-end verdict and kernel replay pending at time of reporting. Not yet confirmed by experts; Alessandro Masullo separately claimed a human proof the same day. Personal claim, not an Anthropic announcement.
