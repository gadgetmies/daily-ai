## ChatGPT Voice gets connector access, runs on GPT-6

OpenAI upgraded ChatGPT's voice mode to run on the GPT-6 model family and, for the first time, gave it the same connector access as text ChatGPT — Gmail, Google Calendar and Drive, Outlook, Microsoft Teams, Slack, GitHub, Box, and Dropbox. Users can talk through tasks like reading a calendar, drafting and sending email, or spotting duplicate charges, hands-free, including inside the work-focused ChatGPT tier (spinning up docs/sheets/slides by voice). Admins control which connectors are enabled and which actions require approval.

- [OpenAI just upgraded ChatGPT Voice in three ways — 9to5Mac](https://9to5mac.com/2026/09/23/openai-just-upgraded-chatgpt-voice-in-three-ways/)
- [ChatGPT Voice gets closer to "Her" with email, calendar and Slack access — The Decoder](https://the-decoder.com/chatgpt-voice-gets-closer-to-her-with-email-calendar-and-slack-access/)

**Horizon:** actionable today.

## Alibaba cuts Qwen Audio pricing up to 95%, ships new voice models

Alibaba refreshed its ASR/TTS/Realtime voice stack and shipped two new models: Qwen-Audio-3.1-TTS-Next (a hybrid language-model-plus-diffusion architecture generating voice, sound effects, and background audio in one pass) and ASR-Next (multi-speaker diarization with timestamps and emotion/ambient-noise detection). Pricing dropped roughly 70% for TTS, 85% for the Realtime API, and up to 95% for transcription versus Alibaba's prior pricing.

- [Alibaba launches Qwen-Audio-3.1 with five new models, slashes AI audio prices by up to 95% — The Decoder](https://the-decoder.com/alibaba-launches-qwen-audio-3-1-with-five-new-models-and-slashes-ai-audio-prices-by-up-to-95-percent/)

**Horizon:** actionable today.

## Xiaomi ships MiMo-V2.6-Pro, the new top open-weights model, trained for $3M

Xiaomi's MiMo-V2.6-Pro is a 1.02-trillion-parameter/42-billion-active-parameter omnimodal mixture-of-experts model with a 1-million-token context window, released under a fully permissive (MIT) license with weights, technical report, training code, and RL environments. Technical notes: hybrid attention ratio increased from 5:1 to 7:1 versus its predecessor, a lightweight multi-token-prediction layer for faster generation, FP8-compute/MXFP4-stored weights, and a "DFlash" speculative decoder. Xiaomi publicly livestreamed the reinforcement-learning training run with a real-time dashboard of spend (a little over $3M total) and benchmark scores, and designed the RL environment to resist reward-hacking by generating tasks from real open-source repositories. Result: debuts at #1 on the Artificial Analysis Intelligence Index among open-weights models, API-priced around $0.435/M input and $0.87/M output tokens.

- [Latent Space AINews: Xiaomi MiMo-V2.6-Pro 1T-A42B](https://www.latent.space/p/ainews-xiaomi-mimo-v26-pro-1t-a42b)

**Horizon:** actionable today.

## TypeSafe launches Jev, a "decision model" category

Jev takes text input and outputs only typed decisions — category probabilities, yes/no with confidence, numeric ratings — rather than generated text, positioned as a cheap, fast substitute for using a full LLM call for classification/routing/scoring tasks. Claimed >100x faster and >200x cheaper than small frontier models on comparable tasks, priced at $0.042/M input tokens with free output. Early independent testers report weaknesses on numbers, dates, and adversarial input.

- [Simon Willison on Jev](https://simonwillison.net/2026/Sep/21/jev/)
- [Latent Space AINews: Jev, a System One model](https://www.latent.space/p/ainews-jev-a-system-one-model-that)

**Horizon:** actionable soon — promising for low-stakes, high-volume classification; not yet validated for adversarial or precision-sensitive use.

## Anthropic's Claude agent swarm flags a novel CRISPR-like enzyme system

Anthropic's biology research group ran roughly 950 Claude agents (about 210M tokens, ~21 hours of focused compute) over bacteriophage genomic data, surfacing a previously uncharacterized enzyme system dubbed "array-associated reverse transcriptases" (ART), structurally resembling CRISPR arrays. This is a preprint, not peer-reviewed, and no function or application has been confirmed — Anthropic is explicit about that.

- [Anthropic: Claude discovers novel enzyme system](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system)
- [Unite.AI coverage](https://www.unite.ai/anthropic-says-claude-discovered-a-new-enzyme-system-resembling-crispr/)

**Horizon:** research/further out — a concrete data point on large-scale multi-agent scientific search, not an actionable result itself.

## Follow-up: SemiAnalysis on the four workloads inside LLM inference

Following up on the mixture-of-experts inference-economics story from a previous episode: SemiAnalysis published a deeper mechanism piece breaking LLM inference into four regimes — Prefill (processing fresh prompt tokens), Midfill (appending to an existing KV cache), Decode Attention, and Decode Experts (routing generated tokens through MoE experts) — arguing each stresses hardware differently, so no single configuration serves all of them optimally. Core claim: memory bandwidth, not HBM capacity, is now the binding constraint for most inference workloads, which is why serious serving operations increasingly split these stages across differently configured hardware pools.

- [SemiAnalysis: Computation and Data Movement for Inference](https://newsletter.semianalysis.com/p/computation-and-data-movement-for)

**Horizon:** research/mental model — directly useful for anyone architecting inference serving or evaluating hardware claims, but not a today/soon action item.
