## 1. Claude Code 2.1.326: auto-mode fallback and sandbox tightening — *actionable today*

Follow-up to 2.1.325 (16 November). Sessions with no mode set now start in **auto mode, not Manual**, when org policy hasn't loaded — set the mode explicitly if you rely on managed policy. Sandboxed commands no longer write to some sensitive home folders by default (`sandbox.filesystem.allowWrite` reopens paths); file tools refuse writes to Claude Code sign-in files such as `.credentials.json`. Code Mode works with agent teams; Remote Control replies stream live; faster long sessions, lower idle CPU.

## 2. VS Code 1.146: Agents inbox, model comparison, Local harness deprecated — *actionable today*

Released 11 November. Experimental **Inbox mode** (`sessions.list.inboxEnabled`) groups agent sessions into needs-attention / running / ready-to-merge, with snooze. **Model comparison** (preview) runs 2–10 configurations side by side, with optional judge and synthesizer roles; agents can launch comparisons via tools; Copilot Fusion supported. The **Local agent harness is deprecated**, removal reported for February 2027; the Copilot harness (Copilot SDK, separate Agent Host) has been default since 1.143 and supports managed sandbox policy.

## 3. Real environments for agents: OpenCode Browse and db-branch — *actionable today*

**OpenCode Browse** (Anomaly): MCP server + Chromium extension that lets any MCP client (OpenCode, Claude Code, Cursor, Codex, Zed) drive your real signed-in browser. Background tabs in collapsed groups, hand-back for login/2FA/payment, idle tabs auto-close (reportedly 10 min), per-site restriction. Launch date reported as 7 November by one source.

**db-branch** (beta, Show HN): disposable MySQL/Postgres branches from ZFS copy-on-write clones of a clean snapshot; each branch is its own DB process on its own port. Project's own cluster: ~0.5 s Postgres, ~3 s MySQL, 0 bytes copied. No merge-back; memory is the main cost. Apache-2.0 core, some paid closed modules.

## 4. Bland Tofu-1 full-duplex speech-to-speech — *actionable soon*

Research preview opened 15 November. Audio in, audio out, no transcription step; full-duplex so it listens while speaking and can be interrupted. Pitched at noisy, degraded calls. No size, latency, pricing, benchmarks or architecture published; enterprise request-only (banking, healthcare, insurance, government); January availability cited. Cascade comparison (~1 s end-to-end for a well-built STT→LLM→TTS pipeline) from AssemblyAI.

## 5. Interpreting coding agents through their behavioral trajectories — *research*

arXiv 2611.17440 (Badertdinov, Golubev; 12 Nov; NeurIPS 2026 IAB workshop). 143,209 SWE-rebench trajectories, 125 agent configurations, 117 models; rule-based parser maps traces to search/edit/test actions (validated against a six-model consensus on 500 events). Scaffold and reasoning effort systematically shift behaviour; outcome-blind profiles identify the agent stack across repos and languages. Examples from excerpts: a Codex stack routed ~31% of recognized edits through native editing vs mostly-native for a Claude Code stack; two GPT-5.6 configurations ran ~12 vs ~3.4 test invocations per task. Takeaway: compare agents on action mix, not just pass rate.

- [arXiv 2611.17440](https://arxiv.org/abs/2611.17440)
