# AI round-up, 22 November 2026

Today's episode covers Databricks Genie ZeroOps, Genie 4 in the Gemini API, parked tools in Cloudflare's Agents SDK, Anthropic's guide to safety evaluations, and agents that design their own self-improvement loops.

## 1. Databricks Genie ZeroOps enters public beta (actionable today)

On 19 November, Databricks put its pipeline operations agent into public beta. It watches jobs, pipelines and tables for hard failures and for slow data-quality decay. It then diagnoses the root cause and proposes a fix on a new branch, with one-click PRs for Git-backed jobs. It never changes code or data without approval. Databricks says it observed more than 80,000 customer issues during the preview, and more than half needed company-specific knowledge. That is why the beta adds custom instructions and shared inboxes, which can be shared with up to 25 individual users. Databricks has not published a rate of merged fixes. Secondary coverage reports the beta is workspace-level and that data quality monitoring is billed separately. A workspace admin enables it from the Previews page.

## 2. Genie 4 in the Gemini API (actionable today; follow-up to 19 Nov)

As of 19 November, the Genie 4 world model is available to developers through the Interactions API (`models/genie-4`) and in AI Studio. It requires a paid-tier key. Sessions are persistent and streaming: a setup event creates the world, then actions and text steering go in while video and audio stream back. Coverage reports 720p at 24 fps. Outputs carry a SynthID watermark. Video output costs $17.50 per million tokens, about $0.10 per second or $6 per minute, and billing continues until `complete()` is called. The 120-second session cap and the per-tier quotas come from secondary sources only.

## 3. Cloudflare Agents SDK 0.34 / Pi 1.6: tools that wait (actionable soon)

PR #2925 was merged on 20 November. With it, a tool call can park and survive Durable Object eviction. It completes when a signal arrives or when its deadline alarm fires. A tool parked only on a signal sets no wake job or alarm. Signals should be delivered with `harness.signal()` rather than `harness.pi().signal()`, because the former arms the wake first and so a crash doesn't strand the call. A separate change lets the harness sleep until the earliest task deadline instead of running on a heartbeat. This release is breaking and one-way: Pi 1.5 cannot run conversations once Pi 1.6 has touched them (`task_too_old`).

## 4. Anthropic: Building strong safety evaluations (actionable today)

Anthropic's Frontier Red Team published this guide on 13 November. It gives about ten recommendations under four headings: safety first, design, run and report. The main ones:
- Use multi-turn evals scored as an "appropriate response rate" over whole conversations, graded against a rubric written by experts.
- Measure over-refusal as well as harmful compliance.
- Validate graders against expert labels made blind to the grader's verdicts.
- Preregister metrics and thresholds before seeing results.
- Use about 100 items or more for multi-turn evals and about 1,000 for single-turn ones. Confidence intervals can be wider than ±10 percentage points.
- Record model, prompt, settings and grader versions.

The 34-point configuration gap comes from secondary coverage.

## 5. Do LLM agents still need to be told how to self-improve? (research)

This is arXiv 2611.23219 by Sundaram, Sancaktar and Isola (MIT CSAIL and Tübingen), posted on 17 November. A frozen teacher model, reported as Claude Opus 5, gets a compute budget, a goal and tools. It collects experience and edits text documents that a player agent reads. The test bed is PuzzleScript games with hidden mechanics, with a 20-turn horizon and a 25k-token budget per game in the main setting. The authors report that capable models devise working learning procedures resembling self-regulated learning frameworks. These transfer to held-out games, different horizons and 3D navigation, and gains plateau as compute grows. The full paper wasn't read for this episode, so no specific scores are quoted.
