# AI round-up, 23 September

A short practitioner-facing AI briefing: two much cheaper OpenAI models, Google's coding agent as an API, a prompt-bloat field guide, a multi-agent supervisor tool, TPU inference economics, and a mental model for AI output you didn't check.

## OpenAI ships GPT-6 Sol and Luna at roughly half the price

OpenAI released two new models, GPT-6 Sol (complex work, including coding) and GPT-6 Luna (high-volume, narrow-goal tasks), at permanent prices roughly half the outgoing GPT-5.6 tier. On the DeepSWE 1.1 coding benchmark, Sol scores 68.8% at max effort (vs. Claude Fable 5's 69.9%) at ~80% lower cost per task; Luna at max effort matches Sol's lower-effort score of 66.6% for $0.22/task vs. $1.00. Live now via the API, ChatGPT Work, and Codex; Luna also reaches Free and Go tiers.

Sources: [TechCrunch](https://techcrunch.com/2026/09/22/openai-launches-gpt-6-sol-and-luna/), [VentureBeat](https://venturebeat.com/technology/openai-releases-gpt-6-sol-and-luna-models-slashing-api-costs-50-or-more), [OpenAI](https://openai.com/index/introducing-gpt-6-sol-and-luna/)

## Google turns Antigravity into a Gemini API tool

The antigravity-preview-09-2026 harness brings Google's Antigravity coding agent (plan/act/observe loop) into the Gemini API's Interactions API and AI Studio, running on Gemini 3.8 Flash, with new Files and Credentials APIs for sandboxed I/O and secure secret handling. Replaces the May preview, which shuts down October 5; existing calls are unaffected until then.

Sources: [Gemini API changelog](https://ai.google.dev/gemini-api/docs/changelog), [AI Studio managed agents update](https://aistudio.google.com/learn/managed-agents-updated-harness-files-credentials), [nokiapoweruser](https://nokiapoweruser.com/google-gemini-agents-update-antigravity-harness-apis/)

## Rethinking skills and prompts for GPT-6 Astra

Eric Provencher (OpenAI, Codex DX lead) argues agent instruction/skill bloat, added to compensate for weaker models, becomes a liability as models improve: too many skill descriptions get truncated to fit context, degrading skill selection. Recommends shorter skill descriptions, re-reviewing AGENTS.md and task prompts on every model switch, and dropping now-unneeded instructions (e.g. explicit "run your tests" nudges GPT-6 Astra no longer needs).

Sources: [OpenAI Developers blog](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra), [the-decoder](https://the-decoder.com/gpt-6-astra-needs-leaner-prompts-and-fewer-guardrails-openai-recommends/), [proflead](https://proflead.dev/posts/gpt-6-astra-codex-prompts-skills-agents-md/)

## agentproto: an open runtime for supervising multiple coding agents

An open-source TypeScript runtime (alpha, v0.14) that runs Claude Code, Codex, or opencode under one daemon, lets you review agent work before it lands, and projects tools/skills/workflows (defined once as files with declared contracts) into CLI, HTTP, MCP, or SDK. Still early-stage.

Sources: [GitHub](https://github.com/agentproto/ts), [agentproto.sh](https://agentproto.sh/)

## SemiAnalysis: Google's Ironwood TPU beats Nvidia on cost per token in matched serving

SemiAnalysis's first independent InferenceX benchmark of TPU v7 "Ironwood" vs. Nvidia B200/B300, at matched FP8 precision and 100 tokens/s/user interactivity, found Ironwood ~19% cheaper than B200 and ~34% cheaper than B300 per million tokens in aggregated serving. Caveat: Google's external stack isn't yet tuned for disaggregated serving (where GB200/300 NVL72 stays competitive), and Ironwood lacks native FP4. A TPU PyTorch integration (TorchTPU) is due to open source in October, which SemiAnalysis expects will close the gap further.

Sources: [SemiAnalysis InferenceX](https://newsletter.semianalysis.com/p/tpu-inferencex-full-steam), [officechai](https://officechai.com/ai/googles-tpuv7-ironwood-achieves-50-better-performance-per-dollar-than-nvidias-blackwell-ultra-says-semi-analysis/)

## Farnam Street: the "Golden Rule of AI"

This month's Brain Food ("Slop") proposes: don't use AI to save yourself time by wasting someone else's. Names the failure mode a "slop grenade" — shipping unchecked AI output and letting the recipient absorb the cost of catching its mistakes. Framing reportedly traces to a conversation with Shopify CEO Tobi Lütke about what stays valuable (judgment, accountability) as agents take on more execution.

Sources: [Farnam Street](https://fs.blog/brain-food/september-20-2026/), [The Algorithmic Bridge](https://www.thealgorithmicbridge.com/p/the-golden-rule-of-ai-is-really-simple)
