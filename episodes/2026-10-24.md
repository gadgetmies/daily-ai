## 1. Agent Skills donated to the Agentic AI Foundation — actionable today (follow-up)
Anthropic donates the Agent Skills name, logo, GitHub organisation and agentskills.io domain to the Agentic AI Foundation (Linux Foundation). Company figures: 70+ platforms, ~1M skills, ~280M installs; roadmap includes versioned releases, proposal process, security guidance.

## 2. Claude Code mods and the "attention interface" — actionable today
Plugins whose hooks module (JS/TS, no build step, Claude Code 2.1.287+) intercepts prompts, tool calls and UI rendering. API details come from one news article and one third-party guide; verify against the docs.
- Latent Space, "Claude Mods": https://latent.space/p/claude-mods
- Claude Code docs, creating mods: https://code.claude.com/docs/en/plugins/mods/create

## 3. TomasuLLM: out-of-order speculative execution for agents — research / soon
Runs predicted future tool calls in sandboxes, commits in order after validation. Reported 1.31x (100 SWE-bench Verified tasks), 1.35x (28 Terminal-Bench 2.0 tasks), 1.27x (18 SWE-Marathon sessions), zero false accepts in 4,010 audited commits. Authors' numbers, no independent replication found.
- Nerra Network summary, 1 Oct 2026: https://buttondown.com/patricknovak1/archive/models-agents-ep190-out-of-order-speculative-execution-for-l/

## 4. Vero: can agents build formally verified repositories? — research
43 multi-module Lean 4 projects, 743 APIs, 2,705 specifications; best configuration fully verified 27/43, 10 unsolved by any configuration, ~87% of individual specifications passed. Authors' summaries; full paper not checked.
- arXiv 2608.13522: https://arxiv.org/pdf/2608.13522
- Berkeley RDI: https://rdi.berkeley.edu/blog/vero

## 5. Kimi K3 cyber evaluation; unconfirmed K3.1 Pro — actionable soon
UK AISI / US CAISI preliminary assessment (July): 32% ExploitBench vs GLM-5.2 24% and leading US models ~76%; no arbitrary code execution on 41 tasks; 17/32 average steps on a simulated network. The report of "Kimi K3.1 Pro" with reduced cyber capability and weights by 4 November is single-source and unconfirmed.
