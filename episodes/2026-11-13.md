## 1. Gemini 4 Hydrogen (actionable today)

## 2. Claude Code 2.1.323: Code Mode and permission fixes (actionable today)

Experimental opt-in Code Mode: Claude writes JavaScript that calls its tools (Bash, Read, Edit, MCP) and returns only the result, cutting turns and context use. Docs page linked from the changelog returned 404 at time of checking. Permission fixes: no "don't ask again" for writes to sensitive paths (`.git`, `.claude`); wildcard allow rules such as `Bash(ls*)` no longer skip prompts incorrectly; rules naming a variable now ask; Write/Edit respected Read deny rules; `claude -p` / Agent SDK stop at startup if sandbox settings fail validation instead of running unsandboxed. Plugins can declare a supported Claude Code range in `plugin.json` (`engines.claude-code`). Unrecognised model IDs now assume 1M context (set `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` for 200K). Follow-up to the Apiiro "don't ask again" secrets finding covered 10 November.

## 3. Amazon replaces Sonnet 4.6 with Strands Decider for ticket labelling (actionable today)

Strands team post (9 Nov, Carr Onstott and Mehul Jaiswal): 20-label ticket classification moved from Claude Sonnet 4.6 to Strands Decider 2B, an open-source decision model (Qwen3.5-2B base, generation head replaced by a pointer head that scores supplied options; yes/no, choice, or rubric score with calibrated probability). Measured: ~4,215 ms to ~897 ms per call, ~6,724 to ~2,010 tokens per ticket. Projected from list prices: ~$22,200 to ~$500 per million tickets (98%). Comparable classification quality per the team. Closed-choice tasks only. Third decision-model data point in a week after Gemini Decision 1 and OpenAI Luna Decisions.

## 5. Inkling 2 Small open weights (actionable soon)

Thinking Machines published Inkling 2 Small weights on Hugging Face on 12 Nov under Apache 2.0 (follow-up to the 10 Nov hosted-only launch). 594B total / 17B active MoE, 8 of 384 experts per token, image input, no native audio. ~394 GB main checkpoint (NVFP4 experts layers 0-39, MXFP8 layers 40-47) plus ~623 GB MXFP8 variant. One write-up notes Apache 2.0 declared in model-card metadata but no LICENSE file at time of check. Serving: SGLang, vLLM, TokenSpeed; fine-tuning via Unsloth; hosted on Together. Lab-reported SWE-Bench Pro v2 Hard 86.3%, Artificial Analysis index 31; third-party Terminal-Bench 4.0 13.1%. Needs ~500 GB accelerator memory.

## 6. BuySideFlow point-in-time audit, and the Maya-site rediscovery (research)

arXiv 2611.12966: 408 investment-research tasks against a frozen licensed database snapshot; nine agent configurations, 16.2% to 36.8% result accuracy. Audit of 900 runs on 100 shared tasks: 193 of 380 result-passing runs (50.8%) had confirmed point-in-time violations (used information unavailable at the question date); the authors' detector caught 49 of 193 (25.4%). Authors note the audit is a subset, not a prevalence estimate. Separately, Pietro Miotti's 48-agent lidar sweep (~1,200 km² of NASA strips) flagged a candidate Maya site; INAH said no registered site at the location; Miotti later revised that a 2025 study (Estrada-Belli et al.) had already mapped it, which the agents' literature check missed.
