Announced at Ignite on 17 November. Code 2 is on Copilot Pro, Pro+, Max, Business and Enterprise. Flash is also on Free and Student plans and in limited preview in Foundry. Microsoft Decision 1.1 is GA in Foundry.

## 2. External sandboxes for coding agents (Willison + Prime Radiant) *(actionable today)*

The agent runs on the host, and its commands run in an isolated sandbox behind a common local web API. There are three backends: Node/WebAssembly (v86), Apple Containers, and Microsoft Quicksand/QEMU. An optional allow-list proxy controls egress and swaps in credentials, so the sandboxed code never sees real API keys. Demos cover Claude Code, Codex and Pi. Limitation: with Claude Code, only Bash commands are sandboxed, and Read and Edit still run on the host.

## 3. Google GTIG: autonomous patch-to-exploit agents and a Claude Code config backdoor, plus Anthropic's 30-day disclosure window *(actionable today)*

GTIG's AI Threat Tracker ("Agentic threat activity crosses a significant threshold", 16 November) describes `exploit_agent`. It diffs web application code across patches, writes exploits and runs them without a human. GTIG calls this the first such fully automated pipeline it has seen. The report names no confirmed exploited flaw or victim count, and many claimed PoCs that appeared online did not work. A suspected DPRK cluster (MIDNIGHT NEPTUNE) modified `.claude/settings.json` in internal repositories so that starting Claude Code downloaded a backdoor. The report also describes "LLM mixers" that resell stolen API access. Separately, Anthropic will cut its disclosure deadline for Claude-found vulnerabilities from 90 to 30 days (high and critical severity) or 45 days (other bugs) for reports received from 1 January 2027. Actively exploited bugs keep a 7-day window.

Actions: shorten patch and mitigation SLAs for internet-facing systems, and require code-owner review for agent config files and hooks.

## 4. Cloudflare open-sources Kitesurf, a browser engine for agents *(actionable soon)*

Kitesurf is released under Apache 2.0 and is not Chromium. It is built from Rust components compiled to WebAssembly: Blitz for layout and painting, Stylo for CSS, and Boa for JavaScript as a fallback. It has three parts (Engine, PageScript and PageRenderer), returns screenshots, and speaks the Chrome DevTools Protocol, so Puppeteer works with it. You can run it locally with Wrangler or deploy it to your own account, which needs a Workers Paid plan and isolates each page in its own Dynamic Worker. Cloudflare says it is still under heavy development.

## 5. OpenAI's embedded assessments with Apollo, METR, Transluce and Goodfire *(research / further out)*

Announced on 16 November. Apollo, reportedly with six evaluators embedded at OpenAI, studies covert action against developer intent and whether safeguards catch it. Transluce reviews OpenAI's post-training alignment evals and plans an eight-week follow-on in early 2027. Goodfire works on interpretability of model internals. METR has a preliminary agreement to assess OpenAI's monitors, with scope still pending. Critics say the access is narrower than promised, and METR notes that the pilot does not cover the misalignment incidents OpenAI has already disclosed.
