Claude Code 2.1.325's new permission defaults, Qwen4-Max general availability, self-hosted Claude Managed Agents, a 1994 Jeep reverse engineered by coding agents, and model swaps that change agent behaviour.

## 1. Claude Code 2.1.325: zstd security fix and stricter defaults for unattended runs *(actionable today)*

- Fixes an unspecified security issue in zstd response decoding; Anthropic has not published scope or affected versions. Third-party trackers reported that as of 14 November the npm `latest`/`next` tags pointed to 2.1.325 while `stable` lagged behind.
- Sandboxed Bash commands now follow the normal permission flow; set `sandbox.autoAllowBashIfSandboxed: true` to restore auto-approval (in the highest-ranking managed source if managed settings enable the sandbox).
- Scheduled tasks and `/loop` now ask before running a skill that declares `allowed-tools` or hooks; add `Skill(name)` to `permissions.allow` to run it unattended.
- "Always allow" in Desktop/IDE/SDK hosts only saves a rule when it would allow the command again, so scheduled tasks relying on such a rule can now wait for input.

## 3. Self-hosted Claude Managed Agents (private beta) *(actionable soon)*

- Opened 12 November; access via Anthropic account team, no public pricing.
- Customer runs the Managed Agents API server and agent loop, PostgreSQL 16+ for agents/sessions/history, and sandboxed workers. Extends May's self-hosted sandboxes.
- `inference.provider`: anthropic (default), bedrock, vertex, foundry, or your own gateway — model traffic only leaves Anthropic's API if you change it. Reported tool limits by provider (web search / web fetch).
- Reported gaps: no hosted environments, Files API, scheduled deployments or webhooks; agents, skills, credentials and memory reportedly must be recreated (not confirmed by all outlets).

## 4. Claude Code and Codex reverse engineer a 1994 Jeep's engine computer *(technique, actionable today)*

- Owner wired a ~$3 Arduino Nano (~$15 parts) to a pre-OBD-II ECU. Claude reportedly identified an inverted serial bus at ~7,800 baud, dumped the 32 KB program image and found the stock logic cutting fuel by ~22%; Codex wrote custom code into EEPROM since reflashing wasn't possible. Car reportedly passed California smog.
- Rests on the owner's video/posts; model used and exact changes unspecified. Modifying emissions-related engine software may have legal implications.

## 5. Identity-preserving agents under model transition *(research)*

- arXiv 2611.10628 (Kang et al., November 2026, not peer reviewed): agent = model + harness (persona, rules, memory) + environment. 5,760 compliance-testing runs, 12 regulated domains, three open-weight models.
- Swapping only the model produces significant behavioural drift for some model pairs and not others; secondary coverage notes self-reported intent is an unreliable migration test. Recommendation: test each transition empirically.
