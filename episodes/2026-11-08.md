# AI round-up, 8 November 2026

A quiet-weekend episode on supervising running agents. Several items rest on search summaries and vendor announcements; the pages themselves could not all be fetched from this environment.

## DigitalOcean Cuttlefish (preview) — actionable today
iPhone app to monitor harness-runtime sessions and approve or deny tool calls; approvals come from the environment's permission policy; high-risk requests need Face ID/passcode; agent questions can't be answered in-app; terms say prompts are conveniences, not safeguards.
- https://digitalocean.com/blog/introducing-cuttlefish
- https://docs.digitalocean.com/products/managed-agents/agent-harness-runtime/how-to/use-cuttlefish-ios-app/
- https://www.digitalocean.com/legal/cuttlefish-preview-terms

## Google Cloud Agent Registry and Agent Gateway — actionable soon
Registry catalogues agents, MCP servers, endpoints and skills; gateway checks the registry and evaluates IAM and content-security policies before routing. Release stage not confirmed; the separately reported compute service could not be verified.
- https://docs.cloud.google.com/agent-registry/overview
- https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern
