# AI round-up, 27 November 2026

Four stories: how Anthropic used Claude agents to move its Messages API from Python to Rust, with production traffic as the check; NVIDIA's open data, fine-tuning recipe and speculative-decoding drafter for Nemotron 3.5 Parse; OpenAI's Private Inference alpha; and a preprint showing models are steered by context words they deny using.

## 1. Anthropic moves the Messages API to Rust, using production as the verifier (actionable today)

Claude wrote the first version of the request path in about a week. Proving it matched the Python version took months. The roughly 700 integration tests were tied to the Python code (more than 100 assertions had been weakened when ported). In April the Rust version passed about 98% of tests but matched only about 24% of production inputs. The team called the model once, replayed its output through both versions, and recorded only the shape of each difference. Agents worked in three loops: a sandbox check that took under a second, a shadow-traffic check after human review, and a memory loop that turned corrections into rules and tests. The match rate reached 99.6% by August. Anthropic reports about 70% less CPU per request, more than 80% less memory, and about 20% lower median time to first token. Caveat: an October account said 40–50% less CPU, and some of the gain likely comes from restructuring the code, not only from Rust.

## 2. Nemotron 3.5 Parse: open datasets, a fine-tuning recipe and a DFlash2 drafter (actionable today)

The 0.63B document parser returns structured text with layout classes, bounding boxes and reading order. On 26 November NVIDIA released about 18.9M synthetic examples (about 9.98M charts, 1M tables and 7.9M multilingual OCR pages), a fine-tuning recipe, and an 89.3M-parameter DFlash2 speculative-decoding drafter. The license is OpenMDW 1.1. Secondary sources report up to 7.62x throughput on one H200 at concurrency 1; this is not confirmed by NVIDIA. Accuracy figures differ between NVIDIA's blog and the model card.

## 3. OpenAI Private Inference alpha (actionable soon)

Sam Altman announced the alpha on 25 November. It uses confidential computing and "verifiable controls" to protect prompts and responses while the model processes them. It is available to a small group of business customers as an API preview, and others can register interest. Coverage mentions in-region GPU inference in the US or EU. OpenAI has not announced which models are supported, pricing, or a general availability date, and coverage describes no attestation mechanism.

## 4. Phantom Context Influence: models deny the words that steer them (research)

Jiang, Lei, Lau, Ehinger and Gao (arXiv 2611.27317, preprint) remove one context word at a time and measure how much the next-token distribution shifts (leave-one-out JSD). Semantically irrelevant words steer reasoning, and the same models say those words are irrelevant when asked. The authors report this across 4 models and 3 benchmarks; the contradiction is strongest in Qwen. Online KV Suppression zeroes the cache entries of the most influential word the model judges inert, which raised chain-of-thought accuracy by up to 8.9 points on math. Only the abstract and summaries were read for this item.
