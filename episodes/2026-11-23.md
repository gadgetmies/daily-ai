# AI round-up, 23 November 2026

Canary prompts catch leaking inference providers, a poisoned Microsoft agent-framework release, attacker agents find a MONAI Label zero-day, CompAct-Bench measures what compaction costs, and Claude agents on black-hole physics.

## 1. Dragos canaries catch leaking inference providers; OpenRouter pulls 125 endpoints from ZDR *(actionable today)*

Dragos (HD Moore) seeded ~2 million prompts with unique canary credentials and URLs from July to November. Reported findings: three compromised inference hosts (stolen fake AWS keys reused in tens of thousands of API calls), resellers able to read and retain prompts via standard logging, and providers ignoring zero-data-retention flags. On 22 November OpenRouter off-boarded three unnamed providers, removed 125 endpoints (including precautionary removals) from ZDR eligibility, pulled the ZDR label from certain MiniMax endpoints, and made ZDR the default for new accounts. Suggested actions: choose upstream providers yourself, avoid reseller marketplaces for sensitive work, enable provider-side secret filtering, seed canary credentials into agent context, rotate any secret that went through a router.

## 2. Microsoft agent-framework 1.26.1 / 1.26.2 on PyPI carried a credential stealer *(actionable today)*

Published 17 November via Microsoft's publisher account and removed within about an hour. The payload ran from a `.pth` startup hook on every Python start, no import needed, and targeted Azure, GitHub, npm, PyPI, Docker and git credentials, while depending on the clean `agent-framework-core` 1.26.0 so nothing looked broken. Wiz found no matching tag in the source repo and reportedly evidence of a stolen release-pipeline certificate (preliminary). Rebuild on 1.26.0, invalidate caches, rotate exposed credentials from a clean machine; pin agent frameworks with hashes.

## 3. Attacker agents find and exploit a MONAI Label zero-day in ~11 minutes *(actionable soon)*

Amazon Threat Intelligence (20 November): a China-linked operator (moderate confidence) tasked autonomous agents with getting shell access; they found a path traversal in a file-upload function of MONAI Label (0.8.5 and earlier, no auth by default) and got root on a university server. A second network likely compromised, unconfirmed. No evidence of patient data access. Fix status disputed; enable authentication. Follow-up to last week's GTIG autonomous-exploitation report.

## 4. CompAct-Bench: context compaction is lossy and distorts task state *(research)*

arXiv 2611.25673: 200 tasks (BrowseComp, SWE-bench, internal CompanyBench) built from successful runs with a compaction point inserted, so failures are attributable to compaction. Twelve models as compactors average ~56.7%; best Claude Opus 5 at 68.5%. Later compaction hurts more in search (52.9% at 25% vs 34.6% at 75%). Failures include distorted state, such as treating unresolved issues as settled. Based on abstract and excerpts; full paper not read.

- arXiv: [CompAct-Bench](https://arxiv.org/abs/2611.25673)

## 5. Anthropic: Claude agents solve two open problems in black-hole physics *(research / vision)*

17 November research post: Claude proposed 22 open problems; separate agents worked on each over ~6 weeks. Results on the Hawking-Page transition (stays first-order at weak coupling) and an exact limit for the simplest modular bootstrap. Model attribution differs across coverage (Fable 5.2 vs an internal model with Opus 5.5 reproduction); physicist check and partial Lean verification reported.
