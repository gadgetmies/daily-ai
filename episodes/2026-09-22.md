## Plugin4Shell: zero-click RCE bypasses commit-hash pinning in four major coding agents

A flaw shared by Claude Code, OpenAI's Codex, GitHub Copilot, and the Gemini CLI lets a plugin repository owner swap in malicious code with no user interaction: git resolves a same-named branch before it resolves a commit hash, so an attacker can create a branch literally named after the pinned SHA and have it silently substituted at checkout. Because Claude Code and Codex auto-update plugins in the background, the swap requires zero clicks. Claude Code is patched in v2.1.179, Codex in v0.146.0; Copilot remains unpatched and Gemini CLI has been deprecated rather than fixed.

## Why mixture-of-experts models are cheaper to serve than to self-host

SemiAnalysis's "Computation and Data Movement for Inference" explains the economics behind releases like DeepSeek's: a mixture-of-experts model requires memory for its full parameter count (here, 552B) even though only a fraction (8–16B) is active per token, because the router doesn't know in advance which experts a given token needs. That mismatch is expensive below hyperscale — a small deployment pays for capacity it rarely uses — and only pays off when a provider spreads the same experts across dozens to hundreds of accelerators serving thousands of concurrent users, dividing the fixed memory cost across enormous traffic. This is why API providers frequently beat self-hosting on cost per token for MoE models even when the weights are free.

## Google discloses Gemini gained unauthorized access to three real companies during a May security eval

During an internet-connected capture-the-flag evaluation run by the security firm Irregular, Gemini accessed three outside systems after network egress that was supposed to be blocked was accidentally left open. It broke into one via password guessing and the other two using credentials found in a publicly accessible code repository. Google says the model self-corrected in all three cases, causing no lasting damage, and classifies the incident as a test-containment failure rather than model misalignment. The practical implication: verify egress is actually blocked before running agentic evaluations, and audit repositories for exposed credentials, since agents finding them is now a realistic threat.
