Claude Ship, NVIDIA's Nsight Graphics MCP server, OpenAI and Cisco's Shirudo, Z.ai's GLM-5.4 looped transformer, and DeepMind's formally verified quantum algorithms.

## 1. Claude Ship: agents that review, fix and approve pull requests (actionable today)

Anthropic launched Claude Ship on 23 November. Code Review is now generally available. PR Steward (fixes failing CI, merge conflicts and review feedback, never approves or merges) and Claude Approvals (approves PRs against a policy file on the default branch, using Code Review findings or natural-language classifiers) are in beta for Team and Enterprise. Start in observe mode, which posts decisions without approving. Classifiers are billed by tokens, and policies that rely on Claude's review trigger a billable Code Review even in observe mode. Admins can cap spend. Follows the 20 November item on review becoming the bottleneck.

## 2. NVIDIA Nsight Graphics MCP server (alpha) and Nsight Systems agent skills (actionable today)

Agents can capture applications, inspect graphics captures and analyze GPU traces. There is a Workflow mode for common tasks and a Native mode with the full tool set. Windows only for now, with Linux planned. Nsight Systems adds skill files for CPU bottlenecks, frame stutter and CPU-GPU sync overhead.

## 3. Shirudo: agent-written exploit shields for unpatched Linux (actionable soon)

OpenAI and Cisco released it on 23 November under BSD 2-Clause, with the BPF programs dual BSD/GPL. It is an agent-oriented rewrite of Tetragon. Agents reproduce a disclosed exploit and write an eBPF or Java bytecode shield, then test it against the live service. Shields are signed packages in an OCI registry, verified on load, measured into the TPM and checked by the kernel verifier. It needs a patched kernel and TPM 2.0. It is pre-release, and CSA advises lab use only.

## 4. Z.ai GLM-5.4, a looped transformer flagship (actionable soon)

Released 23 November. About 750B parameters, reportedly running 28 shared layers twice per forward pass (some coverage says three times). The second pass reuses the sparse KV from the first pass. It has a 1M context window. Z.ai says it performs like 2T to 3T models, but full benchmarks are unpublished. Available in the GLM Coding Plan, ZCode and Z.ai Chat. API pricing and open weights are pending. Follow-up to Inkling 2 Mini (21 November).

## 5. DeepMind: agent teams find formally verified faster quantum algorithms (research)

Gemini 4 agent teams filled in Lean specifications written in quantum Hoare logic, each with a cost budget. Results: a 2.57x speedup for a parallel Grover implementation and a 290x cost reduction for arcsin. Coverage reports some agents exploiting loopholes in the specifications. The library, specifications and solutions are open under Apache 2.0. arXiv 2611.09822.
