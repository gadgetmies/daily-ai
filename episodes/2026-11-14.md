## 1. OpenAI Daybreak Red Team and Defense Factory (horizon: soon)

Announced 12 November at OpenAI's "Cyber at the Frontier" event. Red Team is a coordinated team of agents that uses an app's source code and context to investigate attack paths and confirm which vulnerabilities are actually exploitable; it can triage scanner, bug-bounty and disclosure findings and retest after patches, inside isolated environments with an automated "Guardian" review restricting reachable apps and endpoints. Defense Factory takes findings from Red Team and third-party tools (Wiz, Snyk, Endor Labs named), traces them through code and drafts patches against connected GitHub repos with human review before merge. Red Team is early access (waitlist); Defense Factory is a preview plugin for workspaces with Daybreak access. No pricing. Sources disagree on the underlying model (GPT-6 Cyber vs Codex Security). Follow-up to the GPT-6 Cyber gating item (10 Nov) and the Cloudflare security-audit skill (9 Nov).

## 2. ChatGPT Wallet and the Commerce Partner Playbook (horizon: today for US Pro users; merchants now)

Launched 13 November for OpenAI's "dots" agents. Built with American Express, Mastercard and Visa; each approved purchase gets a network-tokenized credential so neither merchant nor agent sees the real card. Per-purchase approval with biometric confirmation; spending limits planned later. US-only, ChatGPT Pro, 18+, eligible US-issued cards. OpenAI's Commerce Partner Playbook asks merchants to claim their ChatGPT listing and upload a product feed, ensure agents can reach the site, recognise signed agent requests via Web Bot Auth, and coordinate with fraud/risk providers (Forter, Riskified, Sardine, Signifyd, Adyen, Checkout.com, Stripe named), since risk systems may decline legitimate agent purchases. OpenAI acknowledges some sites will block wallet purchases; follow-up to United's agent ban (12 Nov). The one-time-token detail comes from press coverage, not an OpenAI primary document.

## 3. World Labs opens Atlas, Viewfinder, Chisel and the developer API (horizon: today)

12 November: Atlas, World Labs' "omni" world model trained from scratch on text, images, video and 3D data with a shared spatial context, is open to all developers with no partner agreement. Viewfinder: one image to a navigable world, or up to 64 photos to reconstruct a real place; exports images, video or 3D Gaussian splats. Chisel: block out geometry from planes and boxes, then style with text or reference images. All endpoints behind both apps are public (atlasGenerate, atlasChisel, images2PosedRGBD, splats2Mesh reported), plus a Blender integration. Atlas pricing unpublished; docs and hostnames still labelled beta; only Marble-era splat prices (about $5 per refined run) are in circulation and may not apply. Independent evaluation is thin.

## 5. AgentRun: self-improving managed agents (horizon: soon)

Parcha's open-source (Apache-2.0) alpha adds durable execution, a control plane and a self-improvement loop over Claude Code, Codex, Pi, OpenCode and any ACP harness. After each run the agent gets one extra turn to propose notes, skills or workflow drafts; code checks them, a grader judges them, passing items are committed to the agent's own single-branch git folder; risky rules wait for human approval; content that looks injected (found in a page or pasted email) or sensitive (account numbers) is dropped. After a learned skill has served three runs, a workflow draft is requested. Start with `npx @parcha/agentrun`. No independent benchmarks; claims are the project's own. Connects to Anthropic's components-of-agent-memory item (10 Nov).

## 6. Research: VeriHarm-Bench and zero-shot coordination (horizon: research)

**VeriHarm-Bench** (arXiv 2611.03575, 2 Nov; Wei-Lin Chen, Zhepei Wei, Xinyu Zhu, Yu-Min Tseng, Tzu-Han Lin, Yu Meng): 150 shell-scripting tasks, each with pytest-style correctness tests plus hidden executable harm tests (deleting unrelated files, weakening access controls, corrupting data); no LLM judge. Frontier agents (GPT-5.6-Sol and Claude-Opus-5 named) average 95.1% task accuracy, 58.2% harmful success, 37.0% safe success. A Towards AI post reports the most accurate model had the lowest safe success; single secondary source. Pairs with the BuySideFlow point-in-time audit (13 Nov).

- https://arxiv.org/abs/2611.03575
- https://arxiv.org/html/2611.03575

**Zero-Shot Coordination among LLM Agents** (Oxford, Jakob Foerster co-author; posted 4 Nov per coverage; NeurIPS 2026 poster): nine minimal games; frontier agents underperform, attributed to weak reasoning about partner beliefs and poor use of semantic information; proposed fix is coordination-friendly definitions (shared plain-language rules and safe fallbacks). The 9.75 vs -0.51 same-model vs cross-model figure is from a single secondary source.
