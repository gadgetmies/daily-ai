## 1. Fireworks AI breach widens: secrets, datasets and partial model weights (today)

Fireworks AI's 9 November update says a second intrusion on 24 October, via a third-party cloud provider, reached customer billing data and, for a limited set of accounts, stored secrets, uploaded datasets and incomplete model weights. The October disclosure had said there was no evidence of model or dataset access. Fireworks attributes the attack to financially motivated "LLMjacking" criminals, says it does not store card numbers, says Inference, Training SDK and Nexus show no impact (all zero-data-retention by default), and has engaged Palo Alto Networks Unit 42. Notion says some unattributable Notion AI chat sessions may have been exposed.

Action: rotate API keys and any stored secrets with the issuing provider (deleting a stored secret does not revoke it), review access logs and billing for unexpected activity, and if you fine-tuned there, ask which artifacts sat in the affected environment.

## 2. Google open-sources the Elephant-Goldfish Model plugin (today)

Apache-2.0 plugin for Claude Code, Codex CLI, Codex desktop and Antigravity. The "Elephant" (your long-context session) brainstorms, writes a concept brief and drafts a design document; "Goldfish" reviewers are fresh subagents handed only the document and the source files it references, with none of the conversation. Review runs five stages: strategic zoom-out (framing, YAGNI, reuse; can abort), comprehension test, critic pass (design critic, structural, style), intermediate zoom-out auditing only recent changes, and implementation-readiness (write boundaries per file, API signatures match code, test plan). A synthesizer merges findings; `egm-resolve` labels each as propose fix / contest / escalate / decline. Loop ends after two clean rounds, five rounds, or when you stop it. If the harness cannot spawn isolated subagents, the review stops.

Install (Claude Code): `claude plugin marketplace add google/elephant-goldfish-model` then `claude plugin install egm@egm`.

Caveats from reviewers: no published before/after metrics; same model means same blind spots (a clear-but-wrong spec passes); cost is tokens per fresh reviewer.

## 4. AgentScript-Eval: the same skill pack scores 28% as docs, 14% as a plugin (research)

arXiv 2611.13183 (9 November, listed as accepted to NeurIPS 2026). 100 execution-graded tasks for Salesforce's AgentScript DSL: 30 authoring, 40 debugging, 30 optimisation. Best model: 25.0% pass@3; every model 0% on authoring from scratch. Scale and price were weak predictors; a 31B open-weight model had the highest compilation rate. Same skill pack: 28% as inert documentation, 14% as a live plugin, 37% after rewriting only the authoring skill's guidance inside the plugin. Authors' conclusion: wording of domain guidance matters more than packaging.

Single paper, authors' numbers, one proprietary DSL. Cheap to replicate on your own skills: serve the same content as plain markdown and compare.

- https://arxiv.org/abs/2611.13183
- https://arxiv.org/html/2611.13183

## 5. SemiAnalysis "The Iron(wood) Throne": TPUv7 agentic inference results (research / further out)

First long-context, multi-turn agentic inference results for Google TPU v7 on InferenceX/AgentX, submitted jointly by Google and Inferact (founded by vLLM's creators). Inferact's Kimi K3 megakernels plug into vLLM as a model runner replacing only the forward pass, so scheduling, prefix caching and KV transfer are unchanged; Inferact reports 391 tok/s per user. Headline: Google's first submission (FP8, vLLM, Qwen3.5 397B) at ~1.67x performance per dollar vs GB300 NVL72 at FP4; dashboard shows 1.85x tokens per $ TCO on one point. Same dashboard: GB300 NVL72 FP4 on Dynamo/TensorRT-LLM leads at every matched point on both TCO bases. TCO assumptions: $1.03/chip-hour TPUv7 vs $2.31 GB300. DeepSeek-V4-Pro, GLM-5.2, MiniMax-M3 have no TPU v7 results yet. XLA:TPU compiler and multi-pod runtime still not open-sourced.
