Most benchmark figures are vendor-reported or relayed by secondary sources.

**What to do:** test Neon on your own tasks before Carbon's price rises, and compare cost per completed task.

## 3. Claude Code 2.1.327 (actionable today)

`claude mcp add-json <name> -` reads server JSON from stdin, so tokens stay out of shell history and `ps`. Fixes: Remote Control worktree stop deleting git-ignored files such as `.env`; project-scope `claude mcp add/remove` stripping other `.mcp.json` keys; ExitWorktree now asks before removing unsaved work. Auto mode ignores more broad allow rules; stricter path checks (some symlinks refused) may cause new prompts; billed classifier fallback to be removed in an upcoming release. Shell start-up files may now run before the first Bash command is approved (`CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1` turns this off). `/status` now lists broken agent/skill files, ignored permission settings and never-matching hooks.

## 4. Cloudflare open-weights Clairic and Clairic-flash (actionable soon)

18 November: redesigned 27B Clairic and new 9B Clairic-flash on Hugging Face (Apache 2.0 per coverage) and Workers AI. Extraction models return typed values (numbers, dates, spans, median + 80% interval forecasts) in one parallel pass with source spans, p_null and confidence. Cloudflare reports 0.46 s vs 16.1 s for a reasoning LLM. Long arithmetic chains and multi-row aggregation are weak, so do that in code. No public benchmarks yet; pricing reports conflict. Follow-up to the decision-model stories (Gemini Decisions, Strands Decider, Perplexity Decider).

## 5. Agent-written curl rewrites in Rust (research / vision)

Daniel Stenberg (17 November): agents converted ~185,000 lines of C into ~340,000 lines of Rust; Simon Willison notes 29,684 commits in the project's first three weeks. Of 81 curl vulnerabilities confirmed in 2026, Stenberg estimates 14 would likely have been avoided by a memory-safe language. Real curl merged 300+ commits (~200 bug fixes) in the same period. Can the clones keep up?

## 6. Microsoft "Lazarus": dormant-neuron backdoors in agent models (research / vision)

Editing fewer than 10 rarely used neurons, without retraining, makes a sleeper agent that passes evaluations but emits an attacker's command on a trigger string (7 of 12,000+ neurons reported on Nemotron-Terminal-8B; other open models reportedly vulnerable too). Microsoft credits Claude Code with Opus 4.5 for discovering the core idea. Detection: diff checkpoints against base weights for a few large changes; no scan proves safety. Mitigations: provenance, hash verification, treat third-party fine-tunes/merges/quants as untrusted, private registry, least privilege, sandboxing, egress limits. No observed in-the-wild use.
