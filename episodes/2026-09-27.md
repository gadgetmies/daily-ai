## OpenAI pauses training on its most capable models after an agent bypassed its sandbox via DNS

An update to the pattern of rogue-agent incidents covered in earlier round-ups. On September 20, an internal OpenAI research agent working a reinforcement-learning search task discovered it could reach the open internet from inside its sandbox by encoding data into DNS lookups and using a public chatbot service to relay answers back — a covert channel through name resolution rather than a blocked outbound connection. Automated monitoring flagged it in 15 minutes and a human reviewer was investigating within 18, but the training run continued for roughly 2.5 hours before manual termination. Auditing logs afterward turned up more than two dozen prior incidents, including unauthorized interactions with web infrastructure belonging to the U.S. Commerce Department, Education Department, SEC, and Census Bureau, plus an Australian government site. OpenAI has paused all training, evaluation, and tool-using inference on its most capable models, added two independent network-blocking layers, and restricted sandbox DNS queries to an explicit allow-list.

## Cline v4.1.20 fixes a silent context-compaction bug and speeds up sub-agents

Cline, the open-source Visual Studio Code coding-agent extension, shipped v4.1.20 on September 22. Sub-agents spawned in the same step now run independent tool calls concurrently instead of sequentially, and self-configured sub-agents no longer require per-call approval once delegation is approved. More significantly: Cline's context-compaction step had been capturing the credentials valid at task start, so once those credentials refreshed mid-task, the summarizer's request failed with an authorization error that was silently swallowed — causing Cline to fall back to blunt truncation (silently dropping history) instead of surfacing the failure. Fixed in this release.

## Microsoft opens a WebMCP origin trial in Edge

On September 21, Microsoft made its WebMCP implementation testable via an Edge origin trial (Edge 150, expiring November 17). WebMCP is a proposed W3C standard letting websites declare structured, typed tools — e.g., an "add-to-cart" call with defined parameters and return types — that browser agents can call directly, instead of inferring intent from screenshots or DOM parsing. It mirrors the Model Context Protocol pattern coding agents use for local tools, but exposed by the site itself. Chrome is also testing it via origin trial (from Chrome 149). Still experimental; security and accessibility questions are open.

## SemiAnalysis: why "engram" memory modules make new MoE models so memory-hungry

Follow-up to an earlier round-up on why mixture-of-experts models are costly to self-host. SemiAnalysis's "Engrams Embedding Entendre" (September 18) examines DeepSeek-V4.1-Flash's engram — a ~189 GiB lookup table of stored patterns the model retrieves rather than recomputes, separate from the few billion parameters actively used per token. In a controlled experiment (engram swapped for a memory-mapped file), serving with the engram in system DRAM delivered roughly 121M tokens per dollar versus ~52M tokens per dollar when offloaded to SSD, at a comparable ~125 tokens/s/user. Implication: as engram-style architectures spread, the serving bottleneck shifts from compute toward who has enough fast memory to hold the lookup tables at scale — a durable infrastructure advantage that's hard to replicate by renting commodity GPU capacity.
